# ててまる アプリ(モック)

学習支援ロボット「ててまる」の保護者向け・こども向けアプリ画面のモック実装。
フレームワーク不要の素のHTML/CSS/JavaScriptのみで構成されており、GitHub Pagesでそのまま公開できる。

**公開URL**: https://hagoromo1000.github.io/tetemaru-app/

---

## 画面構成

| ファイル | 画面 | 概要 |
| --- | --- | --- |
| `index.html` | メニュー | 起動時のトップ画面。「保護者ホームへ」「こども画面へ」の2択のみ |
| `parent.html` | 保護者ホーム | 今日の学習・今週のようす・質問振り返り・保護者設定 |
| `child.html` | こども画面 | 今日の目標・がんばり・ててまる本体操作(温度)・学習ロック・音声 |
| `study-log.html` | 学習記録(詳細) | 直近7日間の教材ごとの学習ログ(開始〜終了時刻・休憩記録) |

ページ間の移動:
- トップメニュー → 各画面(通常のリンク)
- 保護者ホーム ⇄ こども画面:各ヘッダー右上の小さな切り替えリンク(フッタータブには置かず、役割の切り替えであることを明確にするため)
- 各画面のフッタータブ:同じ役割内でのページ切り替えのみ(保護者:ホーム/学習記録、こども:ホーム/きろく)
- 学習記録ページ:ヘッダーの矢印でメニューへ戻る

---

## 想定ユーザー像(モックデータの前提)

- **ゆい(小学3年生)**
- 得意:理科(生き物・実験が好き)
- 苦手:算数(わり算)
- 3年生で新しく始まる単元(わり算、理科、社会、外国語活動)を中心に教材を設定

全ての学習データ・質問ログは `data.js` にまとめてあり、`parent.html` / `study-log.html` / `child.html` から共通で参照する。

## 主な機能

### 保護者ホーム(`parent.html`)
- 今日の学習(学習時間・取り組んだ問題数・今日の目標と達成バッジ)
- 今週のようす:教科別(算数/国語/英語/理科/社会)の積み上げ棒グラフ。曜日をタップするとその日の合計・教科内訳を表示、「この日の詳細を見る」で学習記録ページの該当日まで遷移
- 質問・振り返り:ててまるに聞いた「わからない問題」をアコーディオンで一覧表示、タップで質問文と解説を展開
- 保護者設定:おやすみモード(時間帯指定)、学習の通知ON/OFF

### こども画面(`child.html`)
- ててまるキャラクター(独自の線画SVG、絵文字は使用していない)とあいさつ
- 今日の目標+「はじめる」ボタン
- 今日のがんばり(達成リング表示)
- ててまるのあたたかさ(ヒーター温度)スライダー ※本体の温度調整はこちら側に集約
- 「ぎゅっとする」ボタン(タップでアニメーション+音声反応)
- **学習ロック機能**:「はじめる」を押すと全画面オーバーレイが表示され、経過時間・目標への進捗バー・「つかえるもの」の明示を行う。解除は保護者による3秒長押しのみ可能(こどもが自分だけで解除できない設計)
  - ※実機化する場合、実際に他アプリを使えなくするにはiOSの「アクセスガイド」やAndroidの画面固定/MDM的な仕組みとの連携が別途必要(本モックは画面上の演出のみ)
- **音声(VOICEVOX連携)**:挨拶・学習開始・学習終了・ハグ時にててまるがVOICEVOXで声を出す。右上の🔊アイコンでON/OFF切替

### 学習記録(`study-log.html`)
- 直近7日分を日付カードで一覧、タップで開閉
- 開くと教材ごとの内訳(教科・教材名・ページ範囲・開始〜終了時刻・所要分)と休憩記録(理由・時間帯・分数)を表示

### 漢字レベル・ふりがな機能(`parent.html` / `study-log.html`)
- 「かんじ レベル」ボタン(1年/2年/3年/ぜんぶ)で表示を切り替え
- 選んだ学年より上で習う漢字の語には自動でふりがな(`<ruby>`)が付く
- 選択はブラウザの`localStorage`に保存され、ページをまたいでも保持される

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要、フレームワーク依存なし)
- `styles.css`:共通スタイル(カラーパレットはポスター準拠:コーラル `#F2707E` / コーラルディープ `#C9435A` / ピーチ `#FFE8E1` / インク `#1C1A1E`)
- `data.js`:モックデータ(学習記録・質問ログ・漢字ふりがな辞書)と共通ヘルパー関数
- `voice.js`:VOICEVOXエンジン(ローカル)と連携する音声再生モジュール
- アイコンは全て自前のインラインSVG(絵文字不使用)

## ローカルでの確認方法

```bash
# このフォルダで簡易サーバーを起動(例:Node.js)
npx serve .
# もしくは任意の静的ファイルサーバーで配信し、index.html を開く
```

### 音声(VOICEVOX)を試す場合
1. [VOICEVOX](https://voicevox.hiroshiba.jp/) を起動しておく(デフォルトで `http://localhost:50021` で待受)
2. `child.html` を開く(GitHub Pages上でもOK。VOICEVOXはPC内で動くため)
3. 挨拶・「はじめる」・学習ロック解除・「ぎゅっとする」のタイミングで、ててまるがVOICEVOX「ずんだもん(あまあまスタイル)」の声でしゃべる
4. VOICEVOXが起動していない場合はエラーにならず、音声なしで動作する
